# واجهة منصة حجز المواعيد وتنظيم الانتظار — مركز النخبة الطبي

واجهة أمامية (Front-End) متكاملة وسريعة الاستجابة (Responsive) مصممة خصيصاً للمراكز الطبية والعيادات التخصصية لحل مشكلة تكدس المراجعين وتنظيم الحجوزات اليومية إلكترونياً قبل الحضور.

---

## المميزات المنفذة (حسب المتطلبات)

1. **الصفحة الرئيسية (Landing Page):**
   - استعراض شامل لـ **6 تخصصات طبية** مع اسم الطبيب المناوب، رقم العيادة، ورقم الدور الحالي والقادم لكل عيادة بشكل مباشر.
   - عرض واضح **لمواعيد العمل الرسمية** (الفترة الصباحية والفترة المسائية) وعنوان المركز.
   - أزرار واضحة ومباشرة للانتقال السريع إلى الحجز الفوري.

2. **نموذج الحجز الذكي (Smart Booking Form):**
   - اختيار التخصص الطبي (مع إمكانية الضغط على أي بطاقة تخصص في الصفحة لاختيارها تلقائياً في النموذج).
   - اختيار يوم المراجعة (اليوم، غداً، والأيام التالية مع استثناء الإجازة الأسبوعية تلقائياً).
   - اختيار الفترة (صباحاً / مساءً) والوقت المتاح، مع توضيح المواعيد المتاحة والمكتملة.
   - إدخال بيانات المريض الأساسية (الاسم الكامل ورقم الجوال) مع التحقق الفوري من صحتها.
   - **معاينة لحظية قبل التأكيد** تعرض للمريض رقم دوره المتوقع ووقت الحضور المقترح بمجرد تغيير التخصص أو الوقت.

3. **شاشة التأكيد وبطاقة رقم الدور (Queue Confirmation Ticket):**
   - تظهر فور إتمام الحجز بتصميم تذكرة طبية واضحة (Perforated Clinical Ticket).
   - تعرض **رقم الدور التقريبي** (مثل `A-15`) و**وقت الحضور المقترح** (قبل الموعد بـ 10 دقائق لمنع التكدس في صالة الانتظار).
   - تعرض كافة تفاصيل الموعد وعدد المراجعين المنتظرين في نفس الفترة، مع زر جاهز **للطباعة أو الحفظ كـ PDF** (`@media print`).

4. **توافق كامل (Mobile-First Responsive):**
   - مصممة لتعمل بسلاسة تامة على الهواتف الذكية (أزرار لمس مريحة، قوائم واضحة، وأرقام باتجاه صحيح `LTR`) وكذلك على شاشات الكمبيوتر والتابلت.

---

## هيكل الملفات

- `index.html` — الهيكل الدلالي للواجهة باللغة العربية (`dir="rtl"`) مع أيقونات SVG خطية نظيفة.
- `style.css` — التنسيقات البصرية المريحة للعين (هوية طبية هادئة، تباين واضح، وتنسيق خاص لطباعة التذكرة).
- `script.js` — منطق التفاعل وحساب أرقام الدخول وأوقات الحضور المقترحة وإصدار التذكرة.

---

## طريقة التشغيل

افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Safari, Edge, Firefox) على الكمبيوتر أو الهاتف، وسيعمل النظام بالكامل دون الحاجة لأي مكتبات خارجية.
